## 📋 Выполненные изменения

### 1. Таблица объектов - Открытия
**Задача:** При нажатии "Добавить открытие" должен открываться модал с типом работ "Открытие" по умолчанию

**Решение:**
- Добавлено поле `defaultWorkType` в store
- Метод `openAddModal` принимает параметр `defaultWorkType`
- В StoreTable при клике на "Добавить открытие" передаётся `workType='Открытие'`
- AddStoreModal использует `defaultWorkType` из store

**Файлы:**
- `src/store/useStore.ts` - добавлено поле `defaultWorkType`
- `src/components/StoreTable.tsx` - передача параметра при открытии модала
- `src/components/AddStoreModal.tsx` - использование `defaultWorkType`

### 2. Таблица объектов - Комментарии и история
**Задача:** В истории изменений нужно отображать ФИО пользователя из справочника users по userId

**Решение:**
- В StoreCard.tsx при отображении истории изменений используется `users.find(u => u.id === log.userId)`
- Отображается `user?.fullName` вместо `log.userName`
- Если пользователь не найден, отображается `log.userName` как fallback

**Файлы:**
- `src/components/StoreCard.tsx` - обновление отображения истории

## 🚀 Обновление на сервере

### Шаг 1: Скопируйте файлы
```bash
cd ~/store-reconstruction
git pull
```

### Шаг 2: Пересоберите backend
```bash
docker compose stop backend
docker compose rm -f backend
docker compose build --no-cache backend
docker compose up -d backend
```

### Шаг 3: Пересоберите frontend
```bash
docker compose stop frontend
docker compose rm -f frontend
docker compose build --no-cache frontend
docker compose up -d frontend
```

### Шаг 4: Проверьте работу
1. **Таблица объектов - Открытия**: Нажмите "Добавить открытие" - должен открыться модал с типом "Открытие"
2. **История изменений**: Откройте объект, перейдите на вкладку "Комментарии и история" - в истории должно отображаться ФИО пользователя
3. **Справочник ТУ**: 
   - Проверьте текст "Территориальные управляющие"
   - Проверьте колонку "Объектов"
   - Проверьте поле поиска
4. **Аудит**: 
   - Проверьте фильтр по подсистеме
   - Создайте/обновите/удалите пользователя, роль или ТУ - должно появиться в аудите
5. **Профиль**: Нажмите кнопку "Профиль" в header - должна открыться страница профиля
6. **Динамический title**: Переходите между страницами - title должен меняться
7. **Заголовок**: В header не должно быть текста "Реконструкция — Закрытие"
