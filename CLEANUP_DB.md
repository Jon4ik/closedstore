# Очистка базы данных — только для тестовой среды

**Не запускайте очистку БД в production.** Она уничтожает объекты, пользователей, комментарии и журнал аудита. API приложения намеренно не позволяет очищать журнал аудита.

Перед любыми разрушительными операциями:
1. Проверьте окружение и адрес PostgreSQL.
2. Сделайте и проверьте резервную копию.
3. Получите подтверждение владельца данных.
4. Остановите приложение и используйте отдельную тестовую БД.

Не удаляйте таблицу `_prisma_migrations` вручную. Для штатного применения миграций используйте `docker compose run --rm migrate`.

Стандартных учётных данных в проекте нет. Первичная учётная запись администратора создаётся через временную переменную `BOOTSTRAP_ADMIN_PASSWORD`; после первичного запуска её необходимо удалить из конфигурации.
