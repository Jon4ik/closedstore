# ⚡ Быстрое решение ошибки Prisma P3005

## Проблема

```
Error: P3005
The database schema is not empty.
```

## Решение (1 минута)

### Шаг 1: Создайте baseline миграцию

```bash
chmod +x baseline-migration.sh
./baseline-migration.sh
```

### Шаг 2: Запустите проект

```bash
./start.sh
```

**Готово!** 🎉

---

## Альтернатива: Очистить базу и начать заново

Если хотите начать с чистой базы:

```bash
chmod +x reset-database.sh
./reset-database.sh

# Затем инициализация
./init-db.sh --sql

# Запуск проекта
./start.sh
```

---

## Что произошло?

Скрипт `baseline-migration.sh`:
1. Создал таблицу `_prisma_migrations` в базе данных
2. Добавил запись о том, что миграция уже применена
3. Prisma больше не пытается применить миграции к существующим таблицам

---

## Проверка

```bash
# Подключитесь к базе данных
psql -h localhost -p 5432 -U your_user -d your_database

# Проверьте таблицу миграций
SELECT migration_name, finished_at FROM _prisma_migrations;
```

Должна быть одна запись:
```
 migration_name      | finished_at
---------------------+------------------------
 20240101000000_init | 2024-01-01 00:00:00+00
```
