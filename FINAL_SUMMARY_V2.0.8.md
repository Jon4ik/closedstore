### 5. БД - userName в audit_logs

**Текущее состояние:** В таблице `audit_logs` хранится поле `userName` (текстовое имя пользователя)

**Решение:** Оставить как есть - это нормальная практика для audit логов.

**Преимущества текущего подхода:**
- ✅ Быстрый просмотр логов без JOIN
- ✅ История сохраняется даже если пользователь удален
- ✅ Производительность при чтении логов
- ✅ Стандартная практика для audit trails

**Как это работает:**
- **Основной источник имени:** `userId` → связь с таблицей `users`
- **Резервный источник:** `userName` из audit_log (если пользователь удален)

Код в `AuditPage.tsx`:
```typescript
const getUserName = (userId: string): string => {
  const user = users.find(u => u.id === userId);
  return user?.fullName || userId; // Если пользователь не найден, показываем ID
};
```
