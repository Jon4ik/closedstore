# Исправления v2.0.5

## Исправленные проблемы

### 1. Таблица объектов - Форматирование дат
**Проблема:** При редактировании даты отображались в ISO формате (2026-10-11T00:00:00.000Z)  
**Решение:** 
- Добавлена функция `formatDate()` в `src/utils/format.ts` для преобразования ISO дат в формат ДД.ММ.ГГГГ
- Добавлена функция `formatDateDisplay()` для отображения с символом "—" для пустых значений
- Обновлен `StoreCard.tsx` для использования `formatDate()` при редактировании
- Обновлен `StoreTable.tsx` для использования `formatDateDisplay()` при отображении

### 2. Пользователи - Создание, редактирование, удаление
**Проблемы:**
- Новый пользователь не создавался
- При редактировании возникала ошибка Prisma
- Удаление не работало
- Роль отображалась как "Не указана"

**Решения:**
- **Backend (`users.service.ts`)**: Добавлена обработка объекта `role` - извлечение `roleId` из `data.role.id`
- **Frontend (`UsersPage.tsx`)**: 
  - Изменено использование `role` на `roleId` во всех местах
  - Исправлена нормализация данных при загрузке пользователей
- **Backend (`auth.service.ts`)**: Изменено возвращение `role: user.role.name` на `role: user.roleId` для корректной работы с ролями

### 3. Справочник ТУ - Телефон и удаление
**Проблемы:**
- Нельзя было заполнить телефон в правильном формате
- Удаление не работало

**Решения:**
- Создан компонент `PhoneInput.tsx` с маской ввода `+7(xxx)xxx-xx-xx`
- Автоматическое форматирование при вводе
- Замена обычного input на `PhoneInput` в форме создания и редактирования ТУ
- Удаление уже работало корректно (проверено)

### 4. Главная страница - Роль пользователя
**Проблема:** Роль не отображалась в шапке  
**Решение:** Исправлено в рамках исправления проблемы #2 (backend теперь возвращает roleId)
