# Исправления v2.0.6

## Исправленные проблемы

### 1. Таблица объектов - Использование input type="date"
**Проблема:** Поля дат использовали text input с ручной валидацией  
**Решение:** 
- Заменены все текстовые поля дат на `input type="date"` в AddStoreModal и StoreCard
- Добавлены функции конвертации `toInputDate()` и `fromInputDate()` для преобразования между форматами DD.MM.YYYY и YYYY-MM-DD
- Убрана ручная валидация дат (input type="date" валидирует автоматически)

### 2. Таблица объектов - Читаемые значения в истории
**Проблема:** В истории изменений записывались ID вместо читаемых значений  
**Решение:**
- В `stores.service.ts` добавлена логика преобразования ID в имена:
  - Для `tuId` записывается имя ТУ вместо ID
  - Для дат форматируется значение в формат DD.MM.YYYY
- Добавлена функция `formatDateForAudit()` для форматирования дат

### 3. Пользователи - Исправление создания, редактирования и удаления
**Проблемы:**
- Пользователи не создавались
- Редактирование вызывало ошибку
- Удаление не работало

**Решения:**
- **Backend (`users.service.ts`)**: 
  - Добавлена обработка объекта `role` - извлечение `roleId` из `data.role.id` или `data.role`
  - Добавлена валидация наличия `roleId`
  - Исправлена логика создания пользователя с правильным маппингом полей
- **Frontend (`UsersPage.tsx`)**:
  - Изменено использование `role` на `roleId` во всех местах
  - Исправлена нормализация данных при загрузке пользователей

### 4. Справочник ТУ - Упрощение интерфейса
**Проблемы:**
- Отображались лишние колонки (Объектов, Статус)
- Валидация телефона конфликтовала с PhoneInput

**Решения:**
- Убраны колонки "Объектов" и "Статус" из таблицы
- Убрана валидация телефона (PhoneInput гарантирует правильный формат)
- Убран select для isActive при редактировании
- Убрана функция `getProjectCount()`

### 5. Аудит - Форматирование дат и отображение объектов
**Проблемы:**
- Даты отображались в формате ISO
- Не было видно, к какому объекту относится запись

**Решения:**
- Добавлена колонка "Объект" с номером и адресом магазина
- Даты форматируются в формат DD.MM.YYYY с временем на отдельной строке
- Добавлен поиск объекта по `storeId` из массива `projects`
