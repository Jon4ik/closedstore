# 📋 Структура проекта

## Основные файлы

### Frontend (React + TypeScript)
```
src/
├── components/          # UI компоненты
│   ├── Layout.tsx       # Основной layout с навигацией
│   ├── Dashboard.tsx    # Панель управления
│   ├── StoreTable.tsx   # Таблица объектов
│   ├── StoreCard.tsx    # Карточка объекта
│   ├── CalendarView.tsx # Календарь
│   ├── AddStoreModal.tsx # Модальное окно добавления
│   ├── ImportModal.tsx  # Модальное окно импорта
│   ├── Filters.tsx      # Фильтры
│   └── LoginPage.tsx    # Страница входа
├── pages/               # Страницы администрирования
│   ├── UsersPage.tsx    # Управление пользователями
│   ├── RolesPage.tsx    # Управление ролями
│   ├── TUsPage.tsx      # Справочник ТУ
│   └── AuditPage.tsx    # Журнал аудита
├── store/               # State management (Zustand)
│   └── useStore.ts      # Основной store
├── types/               # TypeScript типы
│   └── index.ts         # Все типы
├── utils/               # Утилиты
│   ├── statusCalculator.ts  # Расчет статусов
│   └── exportUtils.ts   # Экспорт в Excel
├── data/                # Начальные данные
│   └── seed.ts          # Seed данные
└── config/              # Конфигурация
    └── database.ts      # Конфигурация БД
```

### Backend (NestJS)

backend/

## Скрипты запуска

### Без Docker (WSL/Linux)
- `install.sh` - Установка зависимостей
- `start.sh` - Запуск проекта
- `stop.sh` - Остановка проекта
- `status.sh` - Проверка статуса
- `quickstart.sh` - Быстрый старт для WSL

### Инициализация БД
- `init-db.sh` - Скрипт инициализации (Docker или SQL)
- `init-db.sql` - SQL скрипт для инициализации
- `cleanup-db.sql` - Очистка базы данных

### С Docker
- `Dockerfile` - Dockerfile для frontend
- `backend/Dockerfile` - Dockerfile для backend
- `docker-compose.yml` - Оркестрация контейнеров
- `nginx/nginx.conf` - Конфигурация Nginx

## Документация

- `README.md` - Основная документация
- `README_NO_DOCKER.md` - Запуск без Docker (подробно)
- `DOCKER_DEPLOY.md` - Развертывание с Docker
- `WSL_QUICKSTART.md` - Быстрый старт для WSL
- `INIT_DB_README.md` - Документация по инициализации БД
- `INSTALL_RU.md` - Инструкция по установке (RU)
- `DEPLOYMENT.md` - Полная инструкция по развертыванию

## Конфигурация

- `.env.example` - Пример конфигурации
- `package.json` - Зависимости frontend
- `backend/package.json` - Зависимости backend
- `tsconfig.json` - Конфигурация TypeScript
- `vite.config.js` - Конфигурация Vite

## Логи

При запуске через `start.sh` логи создаются в папке `logs/`:
- `logs/backend.log` - Логи backend
- `logs/frontend.log` - Логи frontend

## Порты

- **5001** - Frontend (React)
- **4000** - Backend API (NestJS)
- **5432** - PostgreSQL (внешняя БД)

## Типы работ

1. **Закрытие** - Закрытие магазина
   - Этапы: Закрытие для покупателей → Демонтаж
   - Цвет: Оранжевый

2. **Реконструкция** - Реконструкция магазина
   - Этапы: Закрытие → Демонтаж → Монтаж → Тех. открытие
   - Цвет: Фиолетовый

3. **Открытие** - Открытие нового магазина
   - Этапы: Монтаж → Тех. открытие
   - Цвет: Зеленый

## Роли и права

### Администратор
- Полный доступ ко всем функциям
- Управление пользователями, ролями, ТУ
- Просмотр аудита

### Менеджер
- Создание и редактирование объектов
- Импорт/экспорт
- Добавление комментариев

### Наблюдатель
- Только просмотр данных
- Просмотр комментариев

## Функционал

### Управление объектами
- Создание, редактирование, удаление объектов
- Фильтрация по типу, статусу, ТУ, городу
- Сортировка по дате закрытия/монтажа
- Экспорт в Excel
- Импорт из Excel

### Карточка объекта
- Вкладки: Основное, Этапы, Комментарии
- Таймлайн этапов
- История изменений
- Множественные комментарии
- Выбор цвета строки

### Календарь
- Просмотр в режиме месяц/неделя/список
- Цветовая индикация этапов
- Клик по событию открывает карточку

### Система ролей
- Гибкая настройка прав по модулям
- Создание/редактирование/удаление ролей
- Назначение ролей пользователям

### Аудит
- Журнал всех действий в системе
- Фильтрация по типу действия
- Поиск по пользователю

### Уведомления
- Уведомления о приближающихся событиях
- Уведомления о просрочках

## Технологии

### Frontend
- React 18
- TypeScript
- Tailwind CSS
- Zustand (state management)
- React Router
- Lucide React (иконки)
- date-fns (работа с датами)
- xlsx (Excel экспорт)

### Backend
- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT авторизация
- bcrypt (хеширование паролей)
- ExcelJS (импорт Excel)

### База данных
- PostgreSQL 13+
- Prisma миграции
- Индексы для оптимизации

## Безопасность

- JWT токены для авторизации
- bcrypt хеширование паролей
- Ролевая модель доступа
- Аудит всех действий
- Защита от CSRF
- Валидация входных данных

## Масштабирование

### Горизонтальное масштабирование
- Stateless backend (можно запускать несколько инстансов)
- Load balancer перед backend
- Redis для сессий (опционально)

### Вертикальное масштабирование
- Увеличение ресурсов сервера
- Оптимизация запросов к БД
- Кэширование (Redis)

## Мониторинг

- Health check endpoint: `/api/health`
- Логи backend и frontend
- Аудит всех действий
- Статус подключения к БД

## Резервное копирование

```bash
# Создание бэкапа
pg_dump -h localhost -p 5432 -U user closestore > backup.sql

# Восстановление
psql -h localhost -p 5432 -U user closestore < backup.sql
```

## Обновление

```bash
# Получение обновлений
git pull

# Обновление зависимостей
./install.sh

# Применение миграций
cd backend && npx prisma migrate deploy

# Перезапуск
./stop.sh
./start.sh
```
