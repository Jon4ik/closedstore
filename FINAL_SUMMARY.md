## Обновление на сервере

### Шаг 1: Скопируйте файлы

```bash
cd ~/store-reconstruction
git pull
```

### Шаг 2: Пересоберите backend

```bash
docker compose stop backend
docker compose rm -f backend
docker compose build --no-cache backend
docker compose up -d backend
```

### Шаг 3: Пересоберите frontend

```bash
docker compose stop frontend
docker compose rm -f frontend
docker compose build --no-cache frontend
docker compose up -d frontend
```

### Шаг 4: Проверьте

```bash
# Проверьте статус контейнеров
docker compose ps

# Проверьте логи backend
docker compose logs -f backend

# Должны увидеть:
# 🚀 Backend running on http://localhost:4000
# 📚 Swagger docs: http://localhost:4000/api/docs
```

## Примечания

1. **Все данные хранятся в PostgreSQL** - нет локального хранилища
2. **JWT токены** сохраняются в localStorage для восстановления сессии
3. **Аудит** записывает все действия пользователей
4. **Soft delete** используется только для объектов (магазинов)
5. **Полное удаление** используется для пользователей и ТУ
