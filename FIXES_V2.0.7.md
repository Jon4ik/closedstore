# Исправления v2.0.7

## Исправленные проблемы

### 1. Пользователи - Редактирование
**Проблема:** Ошибка Prisma "Unknown argument `roleId`. Did you mean `role`?"  
**Причина:** Неправильное использование Prisma API для обновления связи  
**Решение:** 
- Изменен метод `update` в `users.service.ts`
- Используется `connect` для связи с ролью вместо прямого присваивания `roleId`
- Правильная структура данных для Prisma relations

### 2. Пользователи - Удаление
**Проблема:** При удалении пользователь не удалялся из БД, а только деактивировался  
**Решение:**
- Изменен метод `remove` в `users.service.ts`
- Теперь используется `prisma.user.delete()` вместо `prisma.user.update({ isActive: false })`
- Пользователь полностью удаляется из базы данных

### 3. Справочник ТУ - Возврат статуса активности
**Проблема:** Статус активности был убран, но нужен для управления доступностью ТУ  
**Решение:**
- Добавлено поле `isActive` в форму создания ТУ
- Добавлено поле `isActive` в форму редактирования ТУ
- Добавлена колонка "Статус" в таблицу ТУ
- Отображение статуса в виде бейджа (зеленый - активен, серый - неактивен)

### 4. Справочник ТУ - Удаление
**Проблема:** Удаление ТУ не работало (использовался soft delete)  
**Решение:**
- Добавлен метод `deleteTU` в `src/api/client.ts`
- Добавлен метод `remove` в `backend/src/modules/tus/tus.service.ts`
- Добавлен endpoint `DELETE /api/tus/:id` в `backend/src/modules/tus/tus.controller.ts`
- Изменен метод `deleteTU` в `src/store/useStore.ts` для использования полного удаления
- ТУ теперь полностью удаляется из БД (если не используется в объектах)

### 5. Аудит - Отображение ID записи
**Проблема:** В поле "Объект" отображался только номер и адрес, но не ID записи  
**Решение:**
- Изменено отображение объекта в `src/pages/AuditPage.tsx`
- Теперь показывается ID записи (первые 8 символов)
- Если объект найден в projects, дополнительно показывается номер и адрес
- Формат: `ID: abc12345...` + `№123` + `Адрес`

## Технические детали

### Prisma Relations
Для работы со связями в Prisma нужно использовать `connect`:

```typescript
// Неправильно:
{ roleId: "uuid-here" }

// Правильно:
{ role: { connect: { id: "uuid-here" } } }
```

### Полное удаление vs Soft Delete
- **Soft delete**: `prisma.user.update({ data: { isActive: false } })`
- **Полное удаление**: `prisma.user.delete({ where: { id } })`
